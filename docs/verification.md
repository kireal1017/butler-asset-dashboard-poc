## 8. 검증 중 발견해 고친 결함

1. 상세 화면에서 다른 자산으로 이동하면 이전 자산이 그대로 보임 → 라우트 경로로 화면을 다시 마운트하게 고침
2. 홈 화면 폴링이 실패한 수집을 계속 재시작함 → 재수집은 앱을 열 때(`refresh=1`)와 "다시 시도"에서만 하게 고침
3. 미리보기 도구의 `PORT` 환경 변수와 충돌 → 서버 포트 변수 이름을 `API_PORT`로 바꿈
4. 대장 같은 호에 붙은 "대피소" 전유부(3.64㎡)를 호실 면적으로 잡음 → 기타용도로 주거만 받게 고침 (테스트 추가)
5. 오류 문구에 내부 API 이름이 노출됨 → 한국어 안내로 바꿈
6. 매입가 기준선이 1년 그래프의 축 범위 밖으로 벗어남 → 축에 매입가를 포함하게 고침
7. 매칭 0건 화면에 "찾았어요"라는 모순된 문구 → 검색 기간과 건수 안내로 바꿈
8. (완료 리뷰) 후보 검색만 해도 취득 연월이 저장되어, 직접 입력 매입의 보유 기간 시작이 바뀔 수 있음 → 저장은 확정·직접 입력 때만 하도록 고침 (회귀 테스트 추가)
9. (완료 리뷰) 다른 경로로 수집이 끝나도 카드가 "수집 실패"로 남음 → 빠진 달이 있을 때만 실패로 표시 (테스트 추가)
10. (완료 리뷰) 음수 비율 반올림이 비대칭(−2.45% → −2.4%) → 0에서 먼 쪽으로 대칭 반올림 (테스트 추가)
11. (완료 리뷰) 막대 그래프에서 거래 없는 기간의 빈 상태 안내 누락 → 추가
12. (보고서 캡처) 단지 검색이 한글 조합 중인 마지막 글자를 반영하지 않음 → 입력마다 반영
13. (보고서 캡처) 그래프 Y축 단위 오류("5천" → "5천만")와 끝 눈금 겹침, 선형이 계단형과 구분되지 않음 → 수정
14. (보고서 캡처) DB 손상 — Windows 패키지 앱의 AppData 가상화로 DB와 WAL이 다른 실제 파일로 짝지어짐 → 기본 위치를 `~/.butler-poc`로 옮기고 실제 API로 재수집. 재계산 결과 이전과 동일(244개월, 70,141건, 화면 값 72개 불일치 0)
15. (보고서 캡처) SQLite 오류처럼 code가 붙은 내부 오류가 화면에 그대로 노출됨 → 앱이 정의한 오류만 메시지 노출 (테스트 추가)

## 9. 알려진 한계
- 해제 신고가 재수집 범위보다 늦게 들어오면 반영되지 않는다. 개선 v2에서 범위를 최근 3개월 → 12개월로 넓혔다(해제의 90% 이상 포함, 1년 넘게 늦은 해제는 여전히 놓침).
- 단지 목록은 K-APT 가입 단지만 포함한다.
- 지역은 PRD 범위대로 서울만 적재한다(단지 목록 시도 코드 11 고정). 사용하는 API 4종은 모두 전국을 지원하므로, 다른 시도는 목록 적재를 여러 페이지로 받도록 바꾸고 그 지역에서 단지 연결을 실측하면 열 수 있다. 서울 안 다른 구는 등록 시 필요한 달을 API로 자동 수집한다(실제 확인은 노원구·종로구).
