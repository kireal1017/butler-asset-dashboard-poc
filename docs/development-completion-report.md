## 2. 무엇을 만들었나

### 2.1 화면 구성
```mermaid
flowchart LR
  M[전체 메뉴] --> B[건물 관리]
  M --> A[자산 분석]
  M --> L[계약 관리]
  B --> BN[새 건물 등록<br/>주소 바텀시트]
  B --> BD[건물 상세<br/>호실 타일·카드]
  BD --> UN[호실 등록<br/>동·호 → 면적·층<br/>매입가 제안]
  BD --> UD[호실 상세<br/>임대 현황·환산 월세<br/>매입과 시세]
  UD --> AD
  A --> AD[자산 분석 상세<br/>① 내 건물 ② 주변 전월세<br/>③ 매매 시세 ④ 건축물대장]
  L --> LF[계약 등록·수정]
```

| 영역 | 기능 | 캡처 |
|---|---|---|
| 전체 메뉴 | 첫 화면. 하단 탭 없이 건물 관리·자산 분석·계약 관리 3개만 | 01 |
| 건물 관리 | 상태 요약(운영 중·등록 중·확인 필요), 검색, 상태 칩, 입주율 막대 | 02, 17, 19 |
| 건물 등록 | 주소 바텀시트 검색(서울 단지 3,405개), 순서대로 / 한 번에 등록 전환(값 유지), 중복·필수값 막기 | 05~07, 09, 16 |
| 건물 상세 | 임대 중·공실·입주 예정 타일, 호실 카드(계약 없으면 참고가 큰 카드), 성공 안내 | 08, 18, 20 |
| 호실 등록 | 동·호 → 건축물대장으로 면적·층 자동, 취득 연월 → **매입가 제안**(그 달 → 3개월 → 6개월 실거래 평균), 보유 수 도달 시 막기 | 10, 11, 13 |
| 호실 상세 | 임대 현황(상태 뱃지 D-n, **환산 월세**와 전환율 주석), 매입과 시세(참고가·기준일·매입가 대비) | 12, 21 |
| 자산 분석 | 건물 목록 → 상세 4카드, 호실 칩 전환, 참고가 새로고침(1분 제한) | 24~30 |
| 계약 관리 | 요약, 만료 임박 경고와 "해당 계약만 보기", 검색·상태 칩, 등록·수정·삭제, 기간 겹침·날짜 검증 | 03, 14, 15, 22, 23 |

### 2.2 계산 규칙 (요약, 명세 7장)
| 값 | 규칙 |
|---|---|
| 최근 실거래 참고가 | 같은 단지·같은 면적, 기준 월 포함 **최근 12개월** 안의 마지막 거래. 없으면 "최근 12개월 안에 같은 면적 거래가 없어요" |
| 기간별 평균 · 가격 위치 막대 | 1·3·6개월 평균과 건수 / 최근 12개월 범위에 매입가·참고가 표식(5% 여유) |
| 매입가 제안 | 취득 월 → 앞 3개월 → 6개월로 넓혀 같은 면적 실거래 평균, 기간을 밝힘 (v2의 매입 거래 자동 매칭을 대체) |
| 계약 상태 | 오늘(`TODAY`) 기준 진행 중이면 임대 중, 종료까지 **120일 이하**면 만료 임박, 시작 전이면 입주 예정 |
| 건물 상태 · 입주율 | 호실 0개 = 등록 중, 만료 임박 있음 = 확인 필요, 그 밖 = 운영 중 / 임대 중 호실 ÷ 보유 호실 |
| 환산 월세 | 월세 + 보증금 × 전환율 ÷ 12 (전환율은 R-ONE 서울 최신값, 없으면 설정값을 "직접 입력한 값"으로 표시) |
| 주변 전월세 | 같은 단지·±5㎡ 전월세를 6개월(3건 미만이면 12개월)로 환산 → 평균·범위, 내 환산 월세와 ±3% 안이면 "비슷해요" |
| 기간 기준 | 모든 기간은 기준 월(`AS_OF`)에 고정. 등락은 배경 없이 ▲▼와 부호(DESIGN-mobile C4) |

## 7. 기술 구성과 산출물

| 영역 | 구성 |
|---|---|
| 화면 | Vue 3, Vite, vue-router, lucide 아이콘, v3 디자인 토큰(`tokens-v3.css`)과 공통 컴포넌트(`client/src/ui`) |
